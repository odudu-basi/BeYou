# Be You - Design System

## Color Palette

### Primary
- **Background**: #FFFFFF (white)
- **Background Accent**: #F5F5F5 (light gray blend)
- **Card Background**: #1A1A1A (near black)
- **Card Background Alt**: #2A2A2A (dark gray, for hover/active states)

### Text
- **Primary Text (on white)**: #1A1A1A (black)
- **Secondary Text (on white)**: #666666 (gray)
- **Primary Text (on cards)**: #FFFFFF (white)
- **Secondary Text (on cards)**: #A0A0A0 (muted gray)

### Accent
- **TBD** - to be decided based on onboarding screens

## Typography

- **Font Family**: SF Pro (system default on iOS, no custom font needed)
- **Heading Large**: 28px, Bold (700)
- **Heading Medium**: 22px, Semibold (600)
- **Body**: 16px, Regular (400)
- **Body Small**: 14px, Regular (400)
- **Caption**: 12px, Regular (400)
- **Button Text**: 16px, Semibold (600)

## Spacing

- **Screen Padding**: 24px horizontal
- **Section Gap**: 24px
- **Card Padding**: 16px
- **Element Gap (small)**: 8px
- **Element Gap (medium)**: 12px
- **Element Gap (large)**: 16px

## Components

### Cards
- Background: #1A1A1A
- Border Radius: 12px
- Padding: 16px
- No border/shadow (flat design)

### Buttons
- **Primary**: Black background (#1A1A1A), white text, border-radius 12px, height 52px
- **Secondary**: Transparent with #1A1A1A border, black text, border-radius 12px

### Chips/Tags (for multi-select options)
- Background: #2A2A2A
- Text: white
- Border Radius: 20px (pill shape)
- Padding: 10px 16px

### Progress Bar
- Track: #E0E0E0 (light gray)
- Fill: #1A1A1A (black)
- Height: 4px
- Border Radius: 2px

## Layout Principles

- White/light gray backgrounds for screens
- Black cards for content blocks and selectable options
- Clean, minimal, high contrast
- System font throughout (SF Pro on iOS)
- Generous whitespace
